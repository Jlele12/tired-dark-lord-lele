A 100-word villain monologue for a fantasy dark lord who is secretly just very tired — entry for make.fun's "The Tired Dark Lord" bounty. The tiredness lives in the rhythm and the small deflections (the sinking chair, the dim orb, the scheme filed under a housekeeping list) while the speaker stays a villain with a scheme and a history.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

The line is written to `/output/entry.txt` on every run, byte for byte the same.
